[2026-03-16] - WebSockets: fixes para entorno local Windows + ngrok
- Corregido el nombre del constructor de Echo en el blade: era LaravelEcho, es Echo (el CDN IIFE lo expone así).
- Separadas las variables de conexión para PHP vs browser:
    REVERB_HOST=localhost / REVERB_PORT=8080 / REVERB_SCHEME=http → PHP se comunica con Reverb directamente (evita error SSL de cURL en Windows).
    REVERB_CLIENT_HOST / REVERB_CLIENT_PORT → usados en el blade para que el browser se conecte via cloudflare tunnel.
    REVERB_SERVER_HOSTNAME → usado por Reverb para aceptar conexiones del hostname del tunnel.
- Agregada variable REVERB_SERVER_HOSTNAME en config/reverb.php (env('REVERB_SERVER_HOSTNAME', env('REVERB_HOST'))).
- Corregido enabledTransports en el blade: era ['wss'] (inválido), debe ser ['ws'] con forceTLS:true.
- Eliminado php artisan pail del script composer dev (requiere extensión pcntl, no disponible en Windows).
- Para desarrollo se necesitan 5 terminales: ngrok (puerto 8000), cloudflared (puerto 8080), composer dev, reverb:start, schedule:work.
- IMPORTANTE: la URL de cloudflare cambia cada vez que se reinicia cloudflared. Hay que actualizar REVERB_CLIENT_HOST y REVERB_SERVER_HOSTNAME en .env, correr config:clear y reiniciar reverb:start.
